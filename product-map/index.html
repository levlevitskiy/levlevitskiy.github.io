Обучение продакт-менеджера с нуля — Product Map

Product Map — структурированная карта знаний для продакт-менеджеров. Идеально для тех тех, кто хочет самостоятельно пройти обучение продакт-менеджера с нуля и подготовиться к поиску работы.

Карта знаний построена по фреймворку Tripple Diamond: Discovery → Design Solution → Delivery. Подойдет и для начинающих продакт-менеджеров, и для опытных. Фокус на Hard Skills.
